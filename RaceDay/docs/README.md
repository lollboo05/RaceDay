RaceDay

System Description

RaceDay is a web-based event management system designed for the South African road running, walking, and cycling community. The system allows event organisers to manage events, categories, participant enrolments, and race results.

Participants can create accounts, browse upcoming events, enter events, view their enrolments, and track their personal results.

User Roles

Organiser

The Organiser can:

- Create, edit, and delete events.
- Create and manage event categories.
- View participant enrolments.
- Capture participant results.

Participant

The Participant can:

- Create an account.
- Browse available events.
- Enter an event by selecting a category.
- View their own enrolments.
- Track their personal results.
